# Bria for Cursor
Generate and edit commercially licensed images from Cursor, with IP indemnification.

## What it does
- Connects Cursor to Bria's MCP server (19 tools: generation, editing, background removal and more)
- Includes the Bria skill so the agent knows how to use our API

## Setup
Install from the Cursor Marketplace, then sign in to Bria when prompted.
No account yet? Sign up at https://platform.bria.ai
